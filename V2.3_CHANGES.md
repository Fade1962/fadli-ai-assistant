# NARA V2.3 — Concise + Adaptive Daily Radar

Perubahan utama:

- Jawaban chat default dibuat singkat, padat, dan tidak bertele-tele.
- Daily Radar maksimal 4 berita.
- Setiap berita hanya berisi judul, 1 kalimat konteks, dan tombol/link `Buka berita`.
- Tidak lagi menampilkan `Mengapa relevan`, `Aksi konkret`, atau `Potensi uang` kecuali diminta.
- Rating berita didukung langsung dari Telegram, contoh: `1=1/10`, `2=8/10`, atau `/rate 1 1`.
- Rating 1-3/10 menurunkan/menghindari berita serupa pada Daily Radar berikutnya.
- Rating 8-10/10 menjadi sinyal positif untuk seleksi berikutnya.
- Daily Radar dijalankan dari bot realtime pada pukul 06:00 WITA supaya item radar dan rating memakai database yang sama.
- SQLite `data/` disimpan lewat GitHub Actions cache agar preference/memory bisa dibawa ke run berikutnya.
- `daily_scout.yml` sekarang hanya untuk tes manual agar tidak mengirim Daily Radar dua kali.

## Format Daily Radar

Contoh:

```
📡 NARA DAILY RADAR · 11 Agu

1. Shopee gandakan komisi affiliate IG Reels
Peluang affiliate melalui video pendek yang cocok untuk kemampuan produksi kontenmu.
🔗 Buka berita

2. ...

Nilai kalau perlu: 1=8/10 · 2=1/10
```
